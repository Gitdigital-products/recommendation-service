# Recommendation Service

Provides personalized recommendations for users based on:
- User behavior (browsing, purchases, ratings)
- Item similarity
- Popularity/trending analysis

## Features
- REST API with FastAPI
- Machine learning models for recommendations
- PostgreSQL for persistent data
- Redis for caching results
- Swagger docs auto-generated

## Tech Stack
- Python (FastAPI)
- scikit-learn / TensorFlow Lite
- PostgreSQL + Redis
